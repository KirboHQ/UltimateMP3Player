ENGINES (separate programs the app starts)
------------------------------------------

They aren't part of Ultimate MP3 Player's code: the app runs them as programs of their own. Windows: in the "engines"
folder of the installation. Linux and macOS: not in the package, the app downloads them from their projects on its
first start. Android and iPhone: inside the app (see "Android" and "iPhone" below).

yt-dlp (Windows, Android, iPhone)
  License: Unlicense (public domain), text at the end.
  Source: https://github.com/yt-dlp/yt-dlp (each version is a tag there; "yt-dlp --version" shows the one you have).
  yt-dlp.exe contains Python and other libraries:
  https://github.com/yt-dlp/yt-dlp/blob/master/THIRD_PARTY_LICENSES.txt

gallery-dl (Windows)
  License: GNU General Public License version 2, GPL-2.0.txt. Copyright (C) Mike Fährmann.
  Source: https://github.com/mikf/gallery-dl (each version is a tag there; "gallery-dl --version" shows the one you
  have). gallery-dl.exe contains Python and the libraries listed in its source.

FFmpeg: ffmpeg.exe, ffprobe.exe and their DLLs (Windows)
  License: GNU General Public License version 3 (these builds include GPL libraries), LICENSE.txt.
  Built by https://github.com/yt-dlp/FFmpeg-Builds ("ffmpeg-master-latest-win64-gpl-shared").
  Source: the FFmpeg commit named by "ffmpeg -version" (N-...-g<commit>) at https://git.ffmpeg.org/ffmpeg.git
  (mirror: https://github.com/FFmpeg/FFmpeg); the build scripts, with the exact versions of the libraries built into

IPHONE
------

Python 3.15 (Python.framework, its standard library in python/lib, its binary modules as frameworks)
  The official build for iOS from python.org (python-3.15.0-iOS-XCframework.tar.gz), with the libraries it's built with
  (OpenSSL, libffi, SQLite, zlib, bzip2, XZ, mpdecimal, Expat and others).
  License: PSF License, Python-LICENSE.txt; the notices of the libraries inside it in python/lib/python3.15/LICENSE.txt.
  Source: https://www.python.org/downloads/release/python-3150/ and https://github.com/python/cpython (tag v3.15.0).

yt-dlp (python/app/yt-dlp, run by the app's Python) and yt-dlp-ejs (inside it)
  License: Unlicense (public domain), text at the end.
  Source: https://github.com/yt-dlp/yt-dlp and https://github.com/yt-dlp/ejs. yt-dlp-ejs bundles meriyah (ISC) and
  astring (MIT), their notices in its source.

certifi (python/app/certifi): Mozilla's root certificates for Python
  License: Mozilla Public License 2.0, MPL-2.0.txt.
  Source: https://github.com/certifi/python-certifi

LAME 3.100 (Frameworks/mp3lame.framework): the MP3 encoder
  License: GNU Lesser General Public License version 2 or later, LGPL-2.1.txt. Copyright (c) 1999-2017 the LAME
  developers (see the source).
  Source: https://lame.sourceforge.io (lame-3.100.tar.gz), built by tools/ios-deps.sh in this repository. It's a separate
  library inside the app: you can replace it with a modified version built the same way.

umprenew (Frameworks/umprenew.framework, when the app has it): what the app renews and updates itself with
  Part of Ultimate MP3 Player Installer, GNU General Public License version 3, LICENSE.txt, with the Rust libraries it's
  made of (isideload, idevice and others): their notices and licenses are inside the framework
  (App-THIRD-PARTY-NOTICES.txt, THIRD-PARTY-NOTICES.txt, LGPL-2.1.txt).
  Source: https://github.com/KirboHQ/UltimateMP3Player-Installer-Tool (the helper folder; the release is the one named in
  tools/ios-deps.sh). It's a separate library inside the app: you can replace it with a modified version built the same way.
