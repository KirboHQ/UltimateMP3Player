## ✨ What it does

- 🔗 **Paste a link, get the music**: songs, albums and whole playlists from hundreds of sites (yt-dlp inside), or
  search YouTube Music, SoundCloud and Deezer without leaving the app.
- ☁️ **Songs in the cloud**: add a playlist in seconds without downloading it; save on the device only what you want
  offline.
- 🎧 **A player that feels like Spotify**: waveform seek bar, synced lyrics, crossfade, a 10-band equalizer, loudness
  normalization, a queue that fills itself.
- 🏷️ **Your library, your way**: playlists, favorites, coloured tags, followed artists, internet radio, listening
  stats and your year in music.
- 👥 **Listen together**: rooms with friends on your network, computers and phones hearing the same song at the same
  moment, with a chat and a shared queue.
- 📱 **Your phone as a remote**: over Wi-Fi or the cable, it drives the computer's player and shares its library.
- 🎚️ **DJ mode**: two decks, BPM sync, EQ kills, scratching, and your mix recorded into the library.
- 📦 **Bring your music**: Spotify and Last.fm imports, `.ump` packs to share playlists, MP3 folders for the car.

The app keeps itself up to date from the releases. None of the files is signed with a paid certificate, so the system
may warn you the first time:

<details>
<summary><b>Windows</b></summary>
<br>

Run the setup: no administrator rights, nothing else to install. If SmartScreen says the app is unrecognized, click
**More info → Run anyway**.
</details>

<details>
<summary><b>Linux</b></summary>
<br>

Extract it to a folder of yours (not a system one like `/opt`: the app updates itself there) and start it once; from
then on it's in the applications menu:

```sh
mkdir -p ~/.local/opt
tar -xzf UltimateMP3Player-linux-x64.tar.gz -C ~/.local/opt
~/.local/opt/UltimateMP3Player/UltimateMP3Player
```

On plain GNOME the tray icon needs the *AppIndicator* extension. If the app mentions ICU, install your distribution's
`libicu` package.
</details>

<details>
<summary><b>macOS</b></summary>
<br>

Drag **Ultimate MP3 Player** from the zip into *Applications*. The first time, open **System Settings → Privacy &
Security** and click **Open Anyway**. If macOS says the app "is damaged", run once in the Terminal:
`xattr -dr com.apple.quarantine "/Applications/Ultimate MP3 Player.app"`
</details>

<details>
<summary><b>Android</b></summary>
<br>

Open the APK on the phone and allow installing apps from your browser when asked. If Play Protect says the app is
unknown, tap **More details → Install anyway**. New versions download on Wi-Fi and Android asks before installing them.
</details>

<details>
<summary><b>iPhone and iPad</b></summary>
<br>

1. Install [SideStore](https://sidestore.io) following its guide (it uses your free Apple ID, no Mac or jailbreak),
   then turn on **Developer Mode** in Settings › Privacy & Security.
2. In SideStore open **Sources**, tap **+** and add
   `https://github.com/KirboHQ/UltimateMP3Player/releases/latest/download/sidestore-source.json`, then install
   **Ultimate MP3 Player** from there. Updates show up in **My Apps**.

With a free Apple ID an app stays signed for 7 days and SideStore renews it (open it now and then). Downloads need the
app open. To send a link from another app, make a Shortcut that opens `ump://add?url=` followed by the shared URL.
</details>

## 🛠️ For developers

<details>
<summary>Build from source</summary>
<br>

Requirements: .NET 8 SDK, and for the installer Inno Setup 6. Put the external programs in `engines\` (see
[engines/README.md](engines/README.md)).

| Command | Result |
|---|---|
| `.\build.ps1` | Portable app in `app\` and a Desktop shortcut |
| `.\build.ps1 -Installer` | `installer\Output\UltimateMP3Player-windows-x64-setup.exe` and `-windows-arm64-setup.exe` |
| `.\build.ps1 -Release` | `dist\`: every file of a GitHub release: the Windows setups and exes (plus `legacy\UltimateMP3Player.exe` for versions up to 3.6), the Linux and macOS packages and the Android APKs (`-WindowsOnly`, `-NoAndroid`) |
| `.\build-unix.ps1` | Only the Linux and macOS packages (`-Targets linux-x64,…` for some of them) |
| `.\build-android.ps1` | Only the Android APKs in `dist\android\` |

- **Android**: .NET 10 SDK with the Android workload, the Android SDK and a JDK (`ANDROID_HOME` / `JAVA_HOME`, or
  `%LOCALAPPDATA%\Android\Sdk` and `\Android\jdk`); `tools\android-deps.ps1` fetches its engines. The first build
  creates the signing key in `%USERPROFILE%\.ultimatemp3player-android`: **keep a copy of that folder**, Android
  installs an update only if it's signed with the same key.
- **macOS** packages are made on Windows too, signed "ad hoc" with [rcodesign](https://github.com/indygreg/apple-platform-rs).
- **iPhone**: built on macOS by GitHub Actions ([ios.yml](.github/workflows/ios.yml)); a published release gets
  `UltimateMP3Player-ios.ipa` and `sidestore-source.json`. On Windows, `dotnet build src\UltimateMP3Player.iOS` (iOS
  workload) checks the code.
- The version is in the four `.csproj` (`<Version>`, and for Android and iPhone `ApplicationDisplayVersion`).
  `<GitHubRepo>` is where the app looks for updates, `<DiscordAppId>` the Discord application.
- `UMP_DATA=<folder>` runs a test copy with its own data; `src\Mp3Cli` is a command line harness for the core.

| Folder | Content |
|---|---|
| `src\UltimateMP3Player.Core` | Downloads, library, profiles, queue, analysis, translations (no UI) |
| `src\UltimateMP3Player` | Windows (WPF): interface, audio engine (NAudio/WASAPI), DJ engine, updater, Discord |
| `src\UltimateMP3Player.Avalonia` | Linux and macOS: the same interface with Avalonia, sharing the view models and engines |
| `src\UltimateMP3Player.Android` | Android: the phone's pages (Avalonia), the player service, the engines inside the app |
| `src\UltimateMP3Player.iOS` | iPhone and iPad: the Android pages, iOS audio and decoders, yt-dlp in embedded Python |
</details>

<details>
<summary>Where your data lives</summary>
<br>

| System | Songs | Library, settings, `errors.log` |
|---|---|---|
| Windows | `Music\Ultimate MP3 Player` | `%LOCALAPPDATA%\Ultimate MP3 Player` |
| Linux | `~/Music/Ultimate MP3 Player` | `~/.local/share/Ultimate MP3 Player` |
| macOS | `~/Music/Ultimate MP3 Player` | `~/Library/Application Support/Ultimate MP3 Player` |
| Android | `Android/data/com.kirbohq.ultimatemp3player/files/Music` | inside the app |
| iPhone | Files app, *On My iPhone › Ultimate MP3 Player* | inside the app |

The `cache` folder beside the library keeps songs heard without saving them (cloud, suggestions, rooms).
</details>
